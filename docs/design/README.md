# Design Docs

Numbered design documents: `NNNN-short-slug.md` (e.g.,
`0001-event-schema-and-command-surface.md`).

A design doc describes how a piece of the system works. It is a living
document and may evolve as the system does — keep it in sync with the code.

The first design doc, produced by Increment 0 (`GWLJ-rk2cnb`), is
[0001-event-schema-and-command-surface.md](0001-event-schema-and-command-surface.md):
the event schema and command surface, per `docs/specs/job-search-automation-v2.md`.

For point-in-time choices with rationale, use a decision record in
`docs/decisions/` instead.
